# Clone-website (existing stack)

Use the observe-before-building method from https://github.com/JCodesMore/ai-website-cloner-template on **this repo's actual stack**. Do not create a Next.js app, do not import that template's scaffold, and do not copy another site's text, images, or font files.

## 1. Map
Read this project's framework, routes, and owned files. Record source URL → local route. Preserve existing authored routes.

## 2. Observe
Inspect the reference at desktop and mobile. Measure computed styles. Screenshot sections. Treat each observation as a rule, not a one-off rendering.

## 3. Build
Apply layout, type, color, and motion **as a style transfer** onto existing components. Keep this project's copy, logo, accent, photo, and routes unless the user says otherwise.

## 4. Compare
Open reference and local at the same viewport. Fix largest visual gaps. Run the project's production build. List remaining differences honestly.
